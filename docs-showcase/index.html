Technical Foundations

Understanding the core principles that drive Planora's reliability.

Privacy-First Isolation

Unlike traditional SaaS, Planora uses a decentralized identification system. Each browser session is assigned a unique, persistent hash that isolates your task data at the database level, ensuring zero cross-user leakage without requiring a manual login.

Relative Temporal Logic

Our temporal engine enriches AI prompts with the current user's local time and timezone metadata. This allows Gemini to resolve complex relative dates like "next Tuesday" or "in three days" with 99.9% accuracy.

Clean DDD Architecture

The codebase is strictly organized into Domain, Application, and Infrastructure layers. This ensures that the core business logic—orchestration and risk scoring—remains decoupled from external AI providers and database drivers.

Frequently Asked Questions

Is my data shared with the AI?

Only the natural language input is sent to Gemini for orchestration. No personal identifying information or existing task history is shared, preserving your privacy.
